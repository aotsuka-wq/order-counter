# 📱 出店用 カンタン注文・金額集計ツール 
地元の祭りや地域行事で出店（模擬店）を行う際、**「現場での注文集計」「会計時の計算ミス防止」「在庫のカウントダウン」**をスマホ1台で完結させ、運営をラクにするために作成した簡易Webアプリです。 
毎年担当者が変わる場合に合わせ、**「誰でも・教えられなくても・すぐに使える」**シンプルな設計にこだわっています。 

--- 
## ✨ このツールのこだわりポイント（現場目線） 
1. **ワンタッチで売上金がわかる**
   * お客さんから注文された商品をタップするだけで、上部に**現在の合計金額がリアルタイムで大きく表示**されます。電卓を叩く必要がありません。
3. **スクロールしても合計金額を見失わない**
   * 商品数が多くて画面を下にスクロールしても、合計金額エリアが画面の一番上に固定され続けます。
3. **「押し間違い」を防ぐアシンメトリーボタン**
   * カウントを増やす「＋1」ボタンを大きく右側に、間違えたとき用の「ー」ボタンを小さく左側に配置。忙しい現場でのタップミスを徹底的に防ぎます（0未満のマイナスにはなりません）。
4. **売り切れ・残数わずかが一目でわかる「在庫目安機能」**
   * 商品ごとに在庫目安を設定可能。残りが3個以下になると**オレンジ色で警告**、完売すると**画面が赤くなり「＋1」ボタンが自動でロック（無効化）**されます。
5. **万が一、画面を閉じたり充電が切れてもデータは無事**
   * スマホの内部メモリ（ローカルストレージ）に自動で数字が保存されるため、誤ってブラウザを閉じたり、スマホが再起動したりしても、それまでの集計データは消えません。
6. **ログイン・パスワード・アプリのインストール不要！**
   * 使う人は発行されたURLをスマホで開くだけ。毎年の引き継ぎ時に「ログインできない」「パスワードを忘れた」というトラブルが100%起きません。

## 🛠 今後のアップデートで実装可能な機能（拡張アイデア） 
現状でも十分使えますが、今後さらに便利にしたい場合の拡張ロードマップです。
HTML/JavaScriptを少し書き加えることで、以下のような機能が実装可能です。 
* **📊 集計データのCSV書き出し（エクセル連携）**
  * ボタンを1つ追加し、タップされた最終的な「商品名・売れた個数・売上金額」のデータをCSVファイルとしてスマホにダウンロードできるようにします。終わった後の報告書作りが爆速になります。
* **⏰ 時間帯別の売上推移グラフ**
  * 「何時に、どの商品が、何個売れたか」の履歴（タイムスタンプ）を裏で記録し、お祭りの後に「お昼時にフランクフルトが一番売れた」といったデータをグラフで振り返れるようにします。来年の仕入れ量の目安になります。
* **💰 お釣り計算サポート機能**
  * 金額タップエリアを作り、「1,000円預かり」「5,000円預かり」のボタンを押すと、自動でお釣りの金額を表示するミニ電卓機能を画面内に組み込みます。
* **🛠 画面上での「商品名・価格・在庫」の直接編集**
  * 現在はコードを書き換える必要がありますが、管理画面（パスワード付き）を1枚作り、スマホの画面上から簡単に「商品A」を「かき氷」に変更したり、価格をその場で書き換えたりできるようにします。
* **📱 複数スタッフでのリアルタイム同期**
  * 現状は「1人のスマホ」で完結する仕組みですが、Firebaseなどの無料データベースを連携させることで、「3人のスタッフが別々のスマホでポチポチした合算」を1つの画面でリアルタイムに同時集計できるようになります（※ネット環境が必要です）。

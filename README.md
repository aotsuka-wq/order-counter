# order-counter

## 出店用 注文・売上管理ツール

地元のお祭りや地域行事などで使うことを想定した、簡易的な注文・売上管理用のWebアプリです。

スマートフォンやタブレット端末からブラウザで開くだけで使用でき、注文の入力から会計、在庫管理、売上の集計までを1台で行えます。

毎年担当者が変わることを想定し、できるだけ説明なしで使えるシンプルな操作を目指して作成しています。

---

## 現在できること

### 注文入力

商品ごとに「+1」ボタンを押して注文数を入力します。

「-」ボタンで注文数を1個ずつ減らすこともできます。

在庫数を超えて注文することはできません。

### 注文金額の確認

画面上部に現在の注文金額を表示します。

注文内容も画面上で確認できます。

例：

* かき氷 × 2
* たこ焼き × 1

### 会計

複数の商品をまとめて1回の会計として確定できます。

「この注文を確定」を押すと、その注文が本日の売上に追加され、現在の注文は自動的にクリアされます。

「直前の会計を取り消し」を押すと、確定した直前の会計を取り消すこともできます。

「現在の注文だけクリア」を押すと、入力途中の注文を取り消すことができます。


### お釣りの計算

預かった金額を入力すると、お釣りを自動で計算します。

500円、1,000円、5,000円、10,000円のボタンに加えて、金額を直接入力することもできます。

預かり金額が不足している場合は、不足額を表示します。

### 在庫管理

商品ごとに在庫数を設定できます。

在庫が3個以下になると警告を表示します。

在庫が0になると「完売」と表示され、注文ボタンも押せなくなります。

### データ保存

注文内容、確定した売上、販売履歴、商品設定などはブラウザの `localStorage` に保存されます。

ブラウザを閉じても、同じ端末・同じブラウザであればデータを引き続き使用できます。

ただし、別の端末とのデータ同期には対応していません。

### CSV出力

「集計CSVをダウンロード」から、本日の確定売上をCSV形式で保存できます。

出力される項目は以下のとおりです。

* 商品名
* 価格
* 個数
* 売上小計

最後に合計金額も出力されます。

UTF-8 BOM付きで出力しているため、Excelでも文字化けしにくい形式になっています。

途中で商品の価格を変更した場合は、変更前と変更後で別の行として記録されます。

### 時間帯別の売上

会計を確定したときに、商品・個数・販売時刻を販売履歴として保存します。

販売履歴をもとに、時間帯ごとの販売数を商品別に表示します。

どの時間帯にどの商品が売れたかを確認できます。

### 商品設定

画面下部の「商品設定を編集」から、商品情報を変更できます。

管理画面では以下を変更できます。

* 商品名
* 価格
* 在庫数

商品の追加・削除にも対応しています。

設定を保存すると、注文画面やCSV、売上グラフなどにも反映されます。

管理画面にはパスワードを設定しています。

初期パスワードは `1234` です。

変更する場合は、HTML内の `adminPassword` を変更してください。

## 基本的な使い方

1. お客さんの注文に合わせて「+1」を押す
2. 画面上部で注文内容と金額を確認する
3. 預かった金額を入力して、お釣りを確認する
4. 支払いが終わったら「この注文を確定」を押す
5. 次のお客さんの注文を入力する

---

## 1日の終わりに

1. 「本日の確定売上」を確認する
2. 「集計CSVをダウンロード」からデータを保存する
3. 必要に応じて時間帯別の売上を確認する
4. データを翌日に残さない場合は「すべてのデータを0にリセット」を実行する

リセットする前に、必要なCSVデータが保存されていることを確認してください。

---

## 注意点

* 基本的に1台のスマートフォンで使用することを想定しています。
* 複数端末間でのリアルタイム同期には対応していません。
* ブラウザの履歴やサイトデータを削除すると、保存されているデータが消える場合があります。
* `localStorage` を使用しているため、端末やブラウザを変更した場合はデータを引き継げません。

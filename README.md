# 📱 出店用 カンタン注文・金額集計ツール 
地元の祭りや地域行事で大活躍！現場での「注文集計」「お会計」「在庫管理」「売上記録」を、スマホ1台でスマートにこなせる簡易Webアプリです✨
毎年担当者が変わる場合でも、「誰でも・教えられなくても・すぐに使える」を最重要視しています💡 インストール不要で、公開URLやHTMLをスマホで開くだけですぐに使えます！

# 🌟 現在できること
## 🛒 注文入力
・商品ごとに +1 ボタンでラクラク注文追加！
・間違えたときは - ボタンで1個ずつ戻せます（※0個未満にはなりません）。
・残り在庫を超える注文はできない安心設計

## 💰 現在の注文金額
画面上部に「現在の注文金額」が大きく常時表示されます（スクロールしても見失いません）。
金額の下には現在の注文リストをリアルタイム表示！
例：🍧 かき氷 × 2 / ¥200

## 💵 会計確定
複数商品を選んだら、まとめて1回の会計へ
【この注文を確定】を押すと、本日の売上にガッチリ反映
確定後は自動で現在の注文がクリアされ、次のお客さんをすぐにお迎えできます
【現在の注文だけクリア】で、入力中の注文だけを取り消すことも可能。

## 💴 お釣り計算
預かり金額ボタンをポチるだけで、お釣り（または不足額）を瞬時に計算
🔘 500円 🔘 1,000円 🔘 5,000円 🔘 10,000円 ボタンを用意！
金額が足りない場合は不足額を大きくお知らせします

## 📦 在庫管理
商品ごとに在庫数を細かく設定可能
残り3個以下になると警告表示！
在庫0になると完売表示になり、+1 ボタンがロックされます（商品カードも赤系背景にチェンジ）。

## 💾 データ保存
注文途中・確定売上・販売履歴・商品設定はすべてブラウザの localStorage に自動保存
うっかりブラウザを閉じても、同じ端末・同じブラウザならデータがパーフェクトに復元されます（※別端末との自動同期はありません）

## 📊 CSV書き出し
【集計CSVをダウンロード】ボタンで、本日の確定売上をサクッと保存
📋 出力項目：商品名 ｜ 価格 ｜ 個数 ｜ 売上小計 ＋ 最後の行に合計金額
💻 Excelで開いたときも文字化けしにくいBOM付きUTF-8で出力されます

## 📈 時間帯別 売上推移グラフ
会計確定時に「商品・個数・時刻」を販売履歴として自動ストック
時間帯ごとの販売個数を商品別に色分けされた積み上げ棒グラフで視覚化
「何時ごろに何が売れたか」がお祭り後にひと目でわかります

## ⚙️ 商品設定の管理画面
画面下部の【商品設定を編集】から管理画面へアクセス
パスワード入力で、スマホ画面からサクッと変更可能
✏️ 商品名 ／ 💵 価格 ／ 📦 在庫数
保存すると、一覧・注文リスト・CSV・グラフに即時反映されます
🔑 初期パスワード：1234 （変更はHTML内の adminPassword を書き換え）

# 🏃‍♂️ 現場での基本的な使い方
1. 🗣️ お客さんの注文商品を +1 でポチポチ入力。
2. 👀 画面上部の注文内容と現在の注文金額をチェック。
3. 💴 預かった金額のボタンを押して、お釣り・不足額を確認。
4. ✅ 支払いが完了したら 【この注文を確定】 を押す！
5. 🤝 次のお客さんの注文へスムーズにバトンタッチ

# 🌙 1日の終わりにやること
1. 👀 画面下部の 【本日の確定売上】 を最終確認。
2. 📥 【集計CSVをダウンロード】 を押してデータを保存。
3. 📊 時間帯別売上グラフを見て、今日の売れ行きをみんなで楽しく振り返る
4. 🗑️ すべて確認後、翌日にデータを持ち越さない場合は 【すべてのデータを0にリセット】 を押してスッキリリセット

# ⚠️ 注意点・免責事項
📱 基本的に1台のスマホでの運用を想定しています（複数スタッフ間でのリアルタイム同期はありません）。
🗑️ ブラウザの履歴やサイトデータを削除すると、保存データが消える場合があります。
🔄 商品価格を変更しても、すでに確定済みの過去の販売個数はそのまま保持されます。(現在、価格変更に対応できるよう)
🏷️ 価格変更後にCSVを書き出すと、現在の商品価格ベースで売上小計が計算されます。
